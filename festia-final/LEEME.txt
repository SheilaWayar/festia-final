FESTIA - PROYECTO ARREGLADO
===========================

BACKEND (carpeta backend)
  1) pip install -r requirements.txt
  2) Doble clic en start_api.bat  (o:  python -m scripts.seed  y luego
     python -m uvicorn app.main:app --reload --port 8000)
     El seed vuelve a cargar los 4 salones, los tipos de evento y los usuarios.
     Se puede correr cuantas veces quieras: no duplica nada.
     Usuarios: admin@test.com / admin123  -  comun@test.com / comun123

  Si usas Supabase/Render: defini DATABASE_URL en esa terminal ANTES de correr
  "python -m scripts.seed" para cargar los salones en la base online.

FRONTEND (carpeta frontend)
  1) npm install
  2) copiar .env.example a .env  (VITE_API_URL = URL del backend)
  3) npm run dev
